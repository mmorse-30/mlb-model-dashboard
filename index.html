How this works
  • Every bet is 1 unit. Profit is shown in units; type a dollar amount next to "1 unit =" to see dollars.
  • Game lines: for each game the model simulates the score thousands of times. For the total, moneyline and run line it takes the side with the best expected return at the best price across books, and bets it only if that return is positive. Each team total is checked the same way.
  • HR props: the model's chance a hitter homers vs the sportsbook price. It backs (or fades) a player only when the bet is +EV, one bet per player, at the opening price (closing price if no open).
  • Model % = the model's chance the bet wins. Edge = expected profit per unit at that price.
  • Tracked, not on the card: the model also grades every player prop and alternate line it finds +EV. Those are shown for transparency but aren't the daily recommendations.
